# F2 — Kanban: Plano de Implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar a visão Kanban do board — uma coluna por status, mover tarefa por menu de teclado e por arrastar, com rollback em falha.

**Architecture:** O kanban é a MESMA consulta da Tabela Principal recortada por status. `useGruposComTarefas` alimenta as duas views e `useAtualizarTarefa` faz o movimento (`{ status }`). **Nenhum hook novo, nenhuma função de serviço nova.** `src/lib/kanban.ts::colunasPorStatus` já existe, está testado e ainda não tem consumidor — este plano é o consumidor. O caminho acessível (`Menu` "Mover para…") é construído **antes** do arrastar, porque é a solução de mobile e a alternativa de teclado ao mesmo tempo (WCAG 2.5.7) e porque é inteiramente testável em jsdom.

**Tech Stack:** React 19, TypeScript strict, Tailwind v4 (tokens em `src/styles/tokens.css`), TanStack Query, react-router-dom, Vitest + Testing Library, `@dnd-kit/core` (já instalado, parqueado em `knip.json`).

## Global Constraints

Estas valem para **toda** tarefa deste plano. Não são repetidas em cada passo.

- **Zero valor hardcoded** de cor, espaço, raio ou fonte. Só tokens. Isso inclui valor arbitrário do Tailwind: `bg-[#0073EA]` é violação. Não existe `tailwind.config` — os tokens vivem em `@theme` dentro de `src/styles/tokens.css`. Não crie um.
- **Mobile-first.** Classe sem prefixo é 375px; `md:` (768) e `lg:` (1440) são override. Se você escreveu `lg:` para consertar o mobile, inverteu.
- **Alvo de toque 44×44px até 768px:** `min-h-touch md:min-h-0`. Aplicar o tamanho compacto em mobile quebra WCAG 2.5.8.
- **Ícones importados individualmente:** `import { Plus } from 'lucide-react'`. Nunca por namespace — derruba o tree-shaking.
- **Consulta em teste por `getByRole` / `getByLabelText`. NUNCA por classe CSS.** Teste por role é, de graça, um teste de acessibilidade.
- **Não "conserte" um teste alterando a asserção.**
- **Fronteiras verificadas:** `src/components/ui/` não importa domínio nem dados; só `src/services/` importa Supabase. `npm run arch` falha o build se violar.
- **Cor nunca é o único portador de significado (WCAG 1.4.1).** O rótulo em texto vive dentro do badge; o par fundo+texto vem junto do token (`STATUS[s].classe`).
- **Antes de commitar, mostre o diff** (`git diff --staged`) e espere aprovação.
- **Nenhuma dependência nova.** `@dnd-kit/core` já está no `package.json`.
- Comando único de verificação: `npm run verify`. **Leia o exit code de verdade:** `npm run verify > verify.log 2>&1; echo $?`. Encanar (`| head`) devolve o código do `head` — esse erro já foi cometido duas vezes neste projeto.

- Produces:

  - `export function Tabs(props: { items: ItemTab[]; value: string; onChange?: (id: string) => void; variant?: 'underline' | 'pill'; rotulo: string; idPainel?: string; className?: string }): JSX.Element`

**Decisão de design — leia antes de escrever:** `docs/responsive.md` diz que o seletor de views é `Tabs`. Mas `role="tablist"` exige painéis no mesmo documento; trocar de view é **navegação entre rotas**. Um `role="tab"` que na verdade navega mente para o leitor de tela. Resolução: um primitivo, dois elementos — item **com** `href` vira `<nav>` + `<a>` com `aria-current="page"`; item **sem** `href` vira `role="tablist"` + `<button role="tab">`. Isso é "variante, não componente novo" (regra de ouro de `docs/components.md`) e mantém o documento literalmente verdadeiro.

```tsx
import { Link } from 'react-router-dom'
import { cn } from '@/lib/cn'

export interface ItemTab {
  id: string
  rotulo: string
  /** Contagem ao lado do rótulo. Vai para o nome acessível, não só para o olho. */
  contagem?: number
  /** Se presente, o item navega em vez de alternar painel. Ver nota abaixo. */
  href?: string
}

interface Props {
  items: ItemTab[]
  value: string
  onChange?: (id: string) => void
  variant?: 'underline' | 'pill'
  /** Nome acessível da faixa. Obrigatório: faixa sem nome não diz nada. */
  rotulo: string
  /** id do painel controlado pelas abas. Só na variante de abas reais. */
  idPainel?: string
  className?: string
}

/**
 * Faixa de seleção — abas reais OU navegação, decidido pelo `href` do item.
 *
 * `role="tablist"` exige que os painéis estejam no mesmo documento. Trocar de
 * view do board é mudar de ROTA: uma aba que navega mente para o leitor de tela,
 * que anuncia "aba 2 de 4, selecionada" para algo que trocou a página inteira.
 * Por isso item com `href` vira <nav> + link com aria-current="page".
 *
 * Um primitivo, dois elementos — variante, não componente novo.
 */
export function Tabs({
  items, value, onChange, variant = 'underline', rotulo, idPainel, className,
}: Props) {
  // A faixa rola dentro de si mesma em 375px. A PÁGINA nunca rola na horizontal
  // (docs/responsive.md, regra global) — por isso o overflow vive aqui.
  const faixa = cn('flex gap-space-xs overflow-x-auto', className)

  const aparencia = (ativo: boolean) =>
    cn(
      'flex min-h-touch shrink-0 items-center gap-space-xs whitespace-nowrap px-space-md text-body md:min-h-9',
      variant === 'underline'
        ? cn('border-b-2', ativo ? 'border-primary font-semibold text-primary' : 'border-transparent text-ink-muted')
        : cn('rounded-full', ativo ? 'bg-primary font-semibold text-primary-fg' : 'bg-surface-2 text-ink-muted'),
    )

  // O nome acessível traz a contagem junto: "Em andamento, 3 tarefas".
  const nome = (i: ItemTab) =>
    i.contagem === undefined
      ? i.rotulo
      : `${i.rotulo}, ${i.contagem} ${i.contagem === 1 ? 'tarefa' : 'tarefas'}`

  const visual = (i: ItemTab) => (
    <>
      <span aria-hidden="true">{i.rotulo}</span>
      {i.contagem !== undefined && (
        <span aria-hidden="true" className="rounded-full bg-surface-3 px-space-xs text-micro text-ink-muted">
          {i.contagem}
        </span>
      )}
    </>
  )

  if (items[0]?.href !== undefined) {
    return (
      <nav aria-label={rotulo} className={faixa}>
        {items.map((i) => (
          <Link
            key={i.id}
            to={i.href as string}
            aria-current={i.id === value ? 'page' : undefined}
            className={aparencia(i.id === value)}
          >
            <span className="sr-only">{nome(i)}</span>
            {visual(i)}
          </Link>
        ))}
      </nav>
    )
  }

  const mover = (delta: number) => {
    const atual = items.findIndex((i) => i.id === value)
    const proximo = items[(atual + delta + items.length) % items.length]
    if (proximo) onChange?.(proximo.id)
  }

  const tecla = (e: React.KeyboardEvent) => {
    if (e.key === 'ArrowRight') { e.preventDefault(); mover(1); return }
    if (e.key === 'ArrowLeft') { e.preventDefault(); mover(-1); return }
    if (e.key === 'Home') { e.preventDefault(); onChange?.(items[0]?.id ?? value); return }
    if (e.key === 'End') { e.preventDefault(); onChange?.(items[items.length - 1]?.id ?? value) }
  }

  return (
    <div role="tablist" aria-label={rotulo} onKeyDown={tecla} className={faixa}>
      {items.map((i) => (
        <button
          key={i.id}
          type="button"
          role="tab"
          id={`aba-${i.id}`}
          aria-selected={i.id === value}
          aria-controls={idPainel}
          // Só a aba ativa entra na ordem de Tab; as setas fazem o resto (WAI-ARIA).
          tabIndex={i.id === value ? 0 : -1}
          onClick={() => onChange?.(i.id)}
          className={aparencia(i.id === value)}
        >
          <span className="sr-only">{nome(i)}</span>
          {visual(i)}
        </button>
      ))}
    </div>
  )
}
```

```tsx
import { useState } from 'react'
import { Tabs, type ItemTab } from '@/components/ui/Tabs'
import { colunasPorStatus } from '@/lib/kanban'
import { STATUS } from '@/lib/status'
import type { GroupComTarefas, Profile, Task, TaskStatus } from '@/types/domain'
import { KanbanColumn } from './KanbanColumn'

interface Props {
  grupos: GroupComTarefas[]
  membros: Profile[]
  aoMover: (id: string, destino: TaskStatus) => void
  aoAbrir: (t: Task) => void
}

export function KanbanBoard({ grupos, membros, aoMover, aoAbrir }: Props) {
  const colunas = colunasPorStatus(grupos)
  const [visivel, setVisivel] = useState<TaskStatus>(colunas[0]?.status ?? 'not_started')
  const [anuncio, setAnuncio] = useState('')

  /**
   * Um só caminho de movimentação. O menu chama isto hoje; o arrastar (Task 6)
   * chamará exatamente isto. Duas rotas para o mesmo efeito seriam duas chances
   * de esquecer o anúncio.
   */
  const mover = (id: string, destino: TaskStatus) => {
    const tarefa = colunas.flatMap((c) => c.tarefas).find((t) => t.id === id)
    aoMover(id, destino)
    // Calculado no evento que causa a mudança, não num efeito derivando estado.
    if (tarefa) setAnuncio(`${tarefa.title} movida para ${STATUS[destino].rotulo}`)
  }

  const abas: ItemTab[] = colunas.map((c) => ({
    id: c.status,
    rotulo: c.rotulo,
    contagem: c.tarefas.length,
  }))

  return (
    <div>
      {/*
        Faixa de colunas. Em 375px ela é o navegador de coluna (F2.6); de 768px
        para cima as colunas aparecem lado a lado e a faixa sai de cena.
      */}
      <Tabs
        rotulo="Colunas do quadro"
        variant="pill"
        items={abas}
        value={visivel}
        onChange={(id) => setVisivel(id as TaskStatus)}
        idPainel="painel-kanban"
        className="mb-gutter md:hidden"
      />

      {/*
        A mensagem é TEXTO real numa região viva. Sem isto, acionar "Mover para
        Pronto" pelo teclado não produz retorno nenhum — o critério F2.3 exige o
        anúncio, não só a mudança.
      */}
      <p role="status" aria-live="polite" className="sr-only">
        {anuncio}
      </p>

      <div
        id="painel-kanban"
        className="grid grid-cols-1 gap-gutter md:grid-cols-2 md:overflow-x-auto lg:grid-cols-5"
      >
        {colunas.map((c) => (
          <KanbanColumn
            key={c.status}
            coluna={c}
            membros={membros}
            aoMover={mover}
            aoAbrir={aoAbrir}
            // Abaixo de 768px só a coluna escolhida aparece. `hidden` remove do
            // DOM acessível: o leitor nunca encontra 5 colunas onde o olho vê 1.
            className={c.status === visivel ? '' : 'hidden md:flex'}
          />
        ))}
      </div>
    </div>
  )
}

      {...attributes}
      {...listeners}
      className={cn(

```
